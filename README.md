# ProFusion Live

A live production switcher for Mac: cameras, graphics, replays, recording and streaming in one app.

**Download:** the newest zip under [Releases](../../releases/latest). Needs an Apple Silicon Mac with macOS 26 or later.

## Installing (the app is not notarized yet)

1. Unzip and drag **ProFusion Live** to your Applications folder.
2. Open it. macOS will say it can't verify the developer. Go to **System Settings → Privacy & Security**, scroll down and click **Open Anyway** next to ProFusion Live, then confirm.
3. If that doesn't work, run this in Terminal once: `xattr -dr com.apple.quarantine "/Applications/ProFusionLive.app"`

This repository only hosts downloads and the update feed (`appcast.json`).
